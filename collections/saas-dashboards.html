Bundles

SaaS & analytics dashboards

Seven dashboards for a software product: Orrery, a ten-screen console for an AI API platform with a streaming playground, request traces, keys and billing; Prism, a single-screen live analytics wall for an online store; Kestrel, an eleven-page marketing dashboard; Stride, a seven-page personal fitness tracker with a workout log that moves every page; Kairo, a six-page revenue analytics app for a subscription business, where picking a metric morphs the whole report and a deal is dragged into Won; Murmura, an eleven-page social media manager for agencies with role-based access, a composer with live previews for eight networks, approvals, a unified inbox and analytics; and Vitrea, a nine-page App Store publishing desk for an iOS studio in liquid glass, with a release board you drag from build to live, a review inbox, subscriber cohorts, product-page tests and payouts. Plain HTML and CSS with JavaScript or TypeScript (Stride with no dependencies, the others with GSAP), ready to wire to your own data.

  • Orrery — An admin console for an AI API service
  • Prism — A live sales dashboard for an online store
  • Kestrel — A marketing analytics dashboard with eleven pages
  • Stride — A personal fitness tracker dashboard with eleven pages
  • Kairo — A revenue dashboard for subscription businesses
  • Murmura — A social media manager for posting to eight networks
  • Vitrea — An App Store publishing dashboard with an iPhone-style glass look
