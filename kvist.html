A home goods store with an admin dashboard

A complete online home goods store and its admin dashboard in one app. Good for: starting a small online shop. Includes: home, shop with search, product page, checkout, sign-in, order tracking, and a dashboard for sales, orders, products and categories. How it works: it runs in demo mode with sample data, and your Firebase keys turn on real accounts and a database. Payments are not included, so connect Stripe or another provider before you sell. How to use: swap in your own products and photos, and it works on phone, tablet and desktop. Built with React, Tailwind and Firebase.

Version history

  • v1.0.3, 2026-10-14 — A Categories page. A Categories tab in the dashboard sidebar lists every category with its live and draft product counts. Add one, rename it in place (it keeps its shop URL, so links still work), or delete it: if products still use it, you pick where they move and they move in the same step. The five built-in categories stay fixed, since the home page is laid out around them.
  • v1.0.2, 2026-10-14 — Add categories as you go. The category list in the product editor ends with “+ Add category…”: name it, and it is selected for the product, gets its own filter and page in the shop once a live product uses it, and syncs to other open tabs. A name that already exists selects that category instead of making a duplicate. In Firebase mode only admins can add categories, and the rules reject a product whose category does not exist.
  • v1.0.1, 2026-10-13 — Add, edit and delete products. A Products page in the dashboard: add, edit and delete products with a live preview of the card, field checks, image upload, finishes and details. Switch any product between live and draft, filter by low stock, and get a warning before deleting that offers to hide it instead. The catalog now lives in the backend (browser storage in demo mode, a Firestore collection with admin-only rules in Firebase mode), so every edit reaches the storefront straight away.
  • v1.0.0, 2026-10-09 — First release. The store, product pages, bag, checkout, sign-in, account and the live admin dashboard, with demo mode out of the box and Firebase setup included.
