Silo

A download button that opens a box and fills it

A square download button that opens a second box and fills it as the file downloads. Good for: download pages and file libraries. How it works: press it and a box opens beside the button, fills from the bottom with the real download, counts the megabytes and shows a check. How to use: copy the files into your site and point the button at your file. No libraries needed.
