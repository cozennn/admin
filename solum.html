Solum

A clothing store website with checkout and an admin dashboard

A full online store for a clothing or outdoor brand, with an admin dashboard for the owner. Good for: a fashion, sports or outdoor shop. How it works: the home page plays a film as you scroll, shoppers filter products, pick a size, add to the bag and check out, then track their order. Includes: home, shop, product, cart, checkout, order tracking, account, about, help, an admin area for orders, products and customers, and a phone layout. How to use: it comes with sample data and no backend, and payments are not included, so connect your own API and payment provider. Built with TypeScript, HTML and CSS plus GSAP and Lenis.
