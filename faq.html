FAQ — buying, licence, updates and refunds

Short answers about buying from Code and Chill: what is in the download, using it in client work, how long updates last, refunds and the bundle price.

What am I actually buying?

The full source, with a demo page, a README and a ready Vite setup — npm install, npm run dev, and it runs. Most products are plain HTML, CSS and JavaScript, with no framework to adopt; the few React apps say so on their page. No account, nothing that phones home.

Can I use it in client work?

Yes, on unlimited projects, for as long as you like. The one thing you cannot do is resell or redistribute the source as a component library of your own. The licence is one screen and says exactly that.

How long do updates last?

For as long as the store runs. Your download link always serves the newest version, and every release is public on the changelog with a date. A component you bought stays downloadable even if it later leaves the store.

Is there a refund?

Yes. If it does not work the way the demo shows, write to support within 14 days and you get your money back. There is a free product to try first — the same code and the same care as the paid ones.

What happens when I download?

Your copy is yours by name: the email and order you bought with are written into its licence, its readme and the top of each file, with a licence key. Each download is logged so a link passed around can be spotted and switched off. IP addresses are not stored, and the log is kept for about a year.

Why is the bundle cheaper?

Buying them together is less work for both of us. The bundle price is worked out from today’s prices, offers included, so it is always the cheapest way to get every component. Templates are sold on their own or in packs.
